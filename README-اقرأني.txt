Ziedane Quick Entry — حزمة مستقلة للرفع والتثبيت
==========================================

الحزمة دي فيها التطبيق ده لوحده، والمفروض يتحط في **أول (جذر) الـ repo أو الموقع** (index.html لازم يبقى في المستوى الأول).

الرفع على GitHub Pages
-----------------------
1. اعمل repo جديد (خاص لو تقدر) واسمه أي حاجة.
2. فك الـ zip وارفع **كل الملفات اللي جواه** (index.html و manifest.json و sw.js وفولدر icons) في أول الـ repo.
3. Settings ← Pages ← Deploy from branch ← main ← / (root).
4. بعد دقيقة أو اتنين هيظهر الرابط:  https://USERNAME.github.io/REPO/

التثبيت على أندرويد
--------------------
افتح الرابط في Chrome ← قائمة (⋮) ← "تثبيت التطبيق / Install app"
(أو زرار "📲 تثبيت التطبيق" اللي بيظهر فوق في التطبيق نفسه لو ظهر)

ملاحظات
--------
- لازم يتفتح من رابط HTTPS، مش من ملف محفوظ على الموبايل.
- لو هترفعه على Firebase Hosting، اعمل Site منفصل لكل تطبيق (ما ترفعش تطبيقين على نفس الـ Site من حزم مستقلة، هيمسحوا بعض).
- الكود فيه إعدادات Firebase وكلمات سر افتراضية: غيّرها قبل ما الـ repo يبقى عام.
- لو قيّدت الـ API key بنطاقات معينة، ضيف نطاق الاستضافة الجديد.
